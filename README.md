## GPT-1

Решил самостоятельно реализовать GPT-1 в рамках этого репозитория, чтобы закрепить знания по Machine Learning и NLP и лучше понять, как работают Transformer-модели изнутри.

Основная задача — не получить большую или конкурентоспособную языковую модель, а разобраться в основных компонентах GPT:
- токенизация
- embeddings
- self-attention
- multi-head attention
- transformer blocks
- positional encoding
- обучение модели
- генерация текста

Для проекта используется Python 3.6.2.

Выбрал эту версию специально, чтобы ограничить себя более старым окружением и не использовать возможности и готовые решения, появившиеся в более новых версиях Python и библиотек.

## Стек:
- numpy==1.16.6
- torch==1.0.1
- typing==3.7.4.3
- dill==0.3.4

## Цель

Главная цель проекта — разобраться в том, как устроен GPT и пройти процесс реализации основных компонентов самостоятельно, а не просто использовать готовую модель из библиотеки.
